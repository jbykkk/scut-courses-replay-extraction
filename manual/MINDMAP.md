# 课程思维导图

在课程笔记中打开一节已有笔记的课，选择 **思维导图**。导图使用随程序打包的 Markmap 0.18.12，从已保存的分组、知识点与笔记摘录生成，不额外调用模型，也不加载 CDN。没有笔记时，先在“知识点笔记”中生成笔记。

- **浏览**：滚轮缩放、拖动画布、点击圆点展开或折叠。工具栏提供适应画布、展开全部、折叠分支和全屏。
- **出处**：点击带下划线的知识点、课堂原话或课件页码，进入“课件与讲述对照”，查看完整笔记、字幕原句和课件原页。直播录音继续使用独立计时。导图只是笔记的组织形式，不代表新增事实核验。
- **编辑**：打开“编辑提纲”，用 `#` 标题、`##` 分支和 `-` 列表组织内容，实时预览。点击“保存提纲”存到本机。同一课时的其他窗口先保存时，会阻止旧窗口覆盖新版本；可先导出 Markdown 保留修改再合并。
- **更新**：课程笔记重新生成后，手动提纲继续保留并显示版本提示。“从笔记重建”生成最新提纲，点击保存后才替换本机版本。离开有未保存修改的课时会提示。
- **导出**：Markdown 导出当前提纲，SVG/PNG 导出当前展开状态下的完整导图，不受画布缩放与平移影响。PNG 最大边长限制为 4096 像素；大图优先选择 SVG。导出的图片用于浏览；出处跳转在程序内使用。

节点只显示简短摘录，完整内容保留在原笔记中。数学公式按文本展示。Markdown 中的 HTML、远程图片和外部链接不会执行或加载；只有程序生成的出处链接可跳转。单份提纲最多 20 万字符、4000 行、2000 个导图节点，过大的导图可按主题拆分。

本地保存的提纲随课时 `session.json` 一起包含在“导出笔记”的 ZIP 中。扩展和 Windows 安装包会包含导图脚本、样式和第三方许可。依赖重建方法见 [离线资源说明](../scripts/markmap/README.md)。

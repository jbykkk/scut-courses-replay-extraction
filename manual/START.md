# 安装和每天使用

## 第一次

下载 Releases 中的 `SCUT-Study-Setup-0.13.0.exe`，点击“安装并打开”。安装只影响当前 Windows 用户，不需要管理员权限，也不创建开机启动项。

桌面和开始菜单会出现 **SCUT 学习助手**。程序安装在 `%LOCALAPPDATA%\Programs\SCUTStudy\app-0.13.0`；数据单独保存，因此升级不需要重新输入 Key 或搬运笔记。

![首次打开](images/01-first-open.png)

可以先进入学习窗口。想让模型解释资料时，再去“资料与安排 → 模型与连接设置”保存 Key；想整理学校课程时，再连接百步梯。

## 每天

双击桌面图标即可。服务已运行时直接打开窗口；没运行时会先显示启动进度。多次点击入口共用同一个启动过程。窗口关闭后，已提交的任务继续；可以双击桌面图标或通知区域里的助手图标回来。

托盘菜单中的“退出托盘”只关闭这个入口，不会结束后台任务。需要彻底停止服务时，先结束录音和处理任务，再运行程序目录的 `stop-assistant.ps1`。

## 连接学校课程

1. 在对话里说“处理某某课尚未处理的每一节回放”，或点击顶部“连接百步梯”。
2. 首次使用，在 Edge 的 `edge://extensions` 打开开发人员模式，点击“加载解压缩的扩展”，选择连接面板显示的文件夹。Chrome 使用 `chrome://extensions`。
3. 回到学习窗口，重新打开一次。扩展会自动完成本地配对。
4. 点击“打开百步梯”；在学校页面完成登录，打开要处理的课程播放页。校外网络可选“校外入口”。
5. 连接状态显示能读取课程后，等待中的任务自动继续，通常在 30 秒内响应。学校页面需要保持打开，供扩展获取目录和回放地址。

![连接面板](images/03-school.png)

“本地已连接”只表示本机服务可用。“百步梯已连接”来自学校接口读取成功，不会仅因打开一个标签页就声称登录成功。页面跳转到登录界面、校园网络失败、没有选中课程时，都可能需要完成第 4 步；助手不会自动输入账号密码。

## 上课实时字幕

在这节课的播放页，主动点击工具栏上的扩展图标，再点“开始实时字幕”。浏览器需要这次点击授予标签页音频捕获权限。不要关闭学校播放页；学习窗口和课堂详情窗口可以关闭。

实时捕获声音之前，请在设置中选好模型文件夹、FFmpeg 和 CPU/GPU。安装包已包含 Faster-Whisper 运行库，但不包含数百 MB 至数 GB 的语音模型。学校已有字幕的回放不依赖本地语音模型。

## 更新

先等当前任务完成、结束录音，再停止旧服务并退出托盘。安装新版，重新打开桌面入口。数据和 Key 自动沿用，不需要复制进新程序目录。在扩展管理页移除旧程序目录的扩展、加载新版目录；若一直使用同一个源码目录，则点击“重新加载”即可。

源码用户已有的 `.local/` 不会被安装器搬走。继续使用源码时，运行 `install-desktop.ps1` 创建指向原项目的快捷方式即可。如果要迁移到安装版，请先停止服务、备份 `.local/`，再将内容复制到安装版数据目录，避免同时运行两份服务。

## 遇到问题

- **启动进度后没有窗口**：查看数据目录的 `launcher.log`、`server-error.log`；端口 8765 被占用时不会再启动第二个服务。
- **扩展没有连接**：检查是否在同一个浏览器、同一个用户配置中加载扩展；重新打开学习窗口完成本地配对。
- **一直等待学校页面**：打开任务对应课程的播放页，检查该页面是否已登录且能正常播放；校内、校外入口不要混用。
- **有字幕但没有笔记**：检查模型 Key 的保存状态和连接检测；不需要重新转写。
- **转写不可用**：运行库、模型文件、FFmpeg 是三件不同的东西；请按设置中的具体诊断检查。

反馈时给出软件版本、浏览器版本、操作步骤和错误文字即可，不需要发 Key、Cookie 或整份个人数据库。

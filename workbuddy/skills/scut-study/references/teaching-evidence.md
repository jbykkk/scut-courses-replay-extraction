# 教学与证据规程

适用：课程讲解、复习资料、题目、跨来源纠错和作图要求。对应EDU-01至EDU-13、AG-02/03/06/07；普通开发任务不必加载全文。

## 解释一个概念时

从正在解决的问题进入，讲清直觉、机制、符号和适用条件。新概念首次讲解及定义/标题旁直接给英文术语；变量名、英文缩写和最终词汇表不能代替这个动作。之后用一条因果解释或反例验证理解，不要求学生逐字背模型答案。

换模型时说明：研究问题、状态/输入/输出、保留与忽略的信息、近似条件、可检验结果。特别留意把同名符号或同一种数学结构误当相同物理机制；LIF与HH、门控/膜/突触时间常数、试次平均/群体平均、稳定性/任务成功都须区分。

教学深度来自推理与变式，不来自再堆定义。能用计算/反事实说明为什么，并在学生选择练习时让其试一道相近题，选择只讲解时直接展开示例；在原理尚未理解时先停下来，不继续投放整章术语。

连续讲述优先于知识点清单。先说明已有解释在哪里遇到困难，再引入能解决它的概念，展开机制并讲完例子；所得结果自然成为下一段的前提。尽量复用一个情境、数值和符号，换情境时解释共通结构与变化处。模型输入、状态、假设等按推理需要交代，不强制拆成固定标签。清单用于实际步骤、对比和查阅；词表、覆盖索引放在讲述后，不打断正文。检查相邻段落能否直接连读，补推理而非只添“因此/接下来”。

## 图示与考核要求的四条独立证据轴

1. **图源**：PPT确有同图 / 只有相关图 / 教材图 / 讲义自编。给文件、PDF页码和坐标变量；图像识别未完成就明确标未知。
2. **课堂表述**：原句、课时、起止时间、计时基准。讲解、读图、示范画图与要求学生作图不是同一句话。
3. **发言与画面**：教师 / 学生汇报 / 无法确认；直接看过板书 / 只有“在黑板画”的语音 / 未知。不能用语言风格判断身份，也不能用字幕代替视觉证据。
4. **考核强度**：明确考试要求 / 可能相关 / 一般教学强调 / 当前未找到特定要求。保留may/maybe、否定、条件和语境。

在发生作图要求、图解或练习的位置就地写短注，详细证据另存清单。课后统一列个来源表不能替代就地注记。没有找到不等于教师没讲；不确定可查回放或问老师，不凭想象补图。

曲线关系也要核对：横轴是时间、膜电位、状态还是更新步数？纵轴是电流、电导、稳态门控、发放率还是能量？由原式变换后的图必须标“教学重绘”，不能因PPT有相似曲线就宣称是同图或考试原型。

## 原始资料、解释与知识状态

保留原课件与字幕。识别纠正、教师口头简化、教材与课程模型假设不同，分别记录；不悄悄把改写写成老师原话。由同一录音得到的两份转写不构成独立来源。

自编例题、新模型、补充推导明确标出，不据此扩展已确认考核范围。外部检索优先原始论文、教材原文和权威机构，标清阅读范围，来源冲突按主张与条件对照；审查模型意见还需核查。

生成材料不自动写入已确认长期记忆；原文、候选解释、未解决冲突、用户确认的要求和练习自评分开。读取路径、模型凭据和工具执行继续服从当前环境权限，不因技能文件而扩张授权。

## 省token但不丢证据

初次对资料按内容哈希提取并建立定位，后续只读相关页/片段与邻近上下文。不要每个提问重发全课；也不能只保留孤立关键词后丢失条件、前后句与发言者转场。跨课时整理先做证据归并，再讲解；时间线、来源与知识依赖分别建索引。

用户要求完整课程整理时，首次处理应覆盖本机实际保存的全部相关内容，按有界分段与缓存控制成本，不能只读开头或关键词命中段却称“完整”。之后的单题讲解再按定位读取，避免重复全文发送。

## 交付检查

Markdown/PDF另按[数学与代码格式](document-format.md)处理；Skill对应`references/document-format.md`。源稿、数学和代码分别解析，含数学须实际渲染，不能只用正则判断“有美元符号所以支持公式”。

检查概念引入处英文、图示短注、原句回查、公式符号/单位、反例及学习顺序。数值例题独立复算；PDF渲染后看页面；界面和设备行为须实际验证。每个结果写清已检查与未检查的范围，不把“生成了文件”当成“学生已经学会”。

## 推导、答案与时序语义

公式先列符号、依据和适用条件，再给中间步骤与结果检查；输出PDF前检查实际上下标、分式、原图和代码换行。数值独立复算；布尔逻辑在有界变量范围穷举；HDL必须区分编译、仿真、综合和上板，只有真实运行过才能声称通过。

题面与课件答案不一致时并列原页与两个式子，用一个反例说明差异，按实际题面作答，不能悄悄选更顺眼的答案。代码追踪必须包含声明、位宽/范围、敏感表、分支位置与初值；只读几个赋值就下结论会漏掉delta反馈、边沿和越界。

资料覆盖指实际读取与核对范围，不代表所有历史背景都需背诵。交付完整学习资料时保留出处和未核实页段；临近考试先给可用版本，再单列待确认项，不将排版迭代拖成无期限优化。

## 不能把原课件当作标准正确性保证

字幕、课件和自动审查都可能有同一错误。语言规则优先核对实际标准包、编译/仿真或权威原文，再列课程表述差异；不由多个相同来源或模型一致推出独立核验。特别避免把std_logic说成八值、禁止numeric_std的signed/unsigned逻辑运算、把wait until限定为单信号首行、或把rising_edge无条件等同于event且为1。标清版本与已验证情景，不将这些检查冒充所有代码的综合/上板证明。

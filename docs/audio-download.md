# 回放音频下载

本项目可以从课程回放 MP4 中提取 AAC 音轨，供平台没有字幕或字幕质量不佳时另行转写。浏览器插件和命令行都支持下载音频，二者的登录方式、输出目录和实现不同。

## 浏览器插件

在扩展管理页重新加载本项目的 `extension/` 目录后，可以使用以下音频入口：

- **当前课时**：点击“下载本次回放音频 (M4A)”。
- **已选课时**：在“全部课时”勾选需要的回放，点击“下载已选课程音频”。列表顶部复选框用于全选或全不选；没有勾选时按钮禁用。未来课时、直播中和暂无回放的课时不在列表内。
- **暂无字幕后补下载**：完成一次字幕导出后，如果存在“暂无字幕”的课时，会出现对应按钮；该入口只处理这些课时，不包含请求失败的课时。

音频任务会打开独立下载页，并逐节保存到浏览器下载目录中的 `audio_<课程名称>_<下载时间>/`，例如 `audio_示例课程_下载时间/`。时间使用任务开始时的本地时间，格式为 `YYYY-MM-DD_HH-mm-ss`；同一批次的音频、重试文件和结果报告共用该目录。无法获取课程名称时使用课程 ID。

任务页支持取消、重试未完成的课时，以及下载包含媒体地址、时长、文件大小、读取方式和读取量的结果报告。已完成的课时不会在同一次任务重试时重复下载；新任务按开始时间建立目录，同名文件由浏览器自动重命名。可以关闭插件弹窗，但请在任务结束前保留下载页。

### 实现与限制

插件内置 MP4Box.js，在浏览器内将回放 AAC 音轨重新封装为真正的 M4A 文件，不重新编码，也不需要安装 ffmpeg。默认先读取 MP4 索引，再按音轨所在字节范围读取，减少视频数据传输；站点不支持范围读取或返回不兼容数据时，会自动回退为完整读取回放。

当前支持两个华园视频站点上的普通 MP4/AAC 回放，单个媒体文件上限为 1 GB。HLS、其他音频编码以及更大的文件暂不支持。插件的媒体请求会携带当前浏览器会话；取消和登录错误不会触发回退。

字幕导出期间音频入口会暂时禁用，避免新标签页关闭弹窗而中断字幕导出。字幕格式、ZIP 内容和导出报告不受影响。

## 命令行

CLI 的 `audio` 命令复用 Playwright 保存的登录态，使用本机 ffmpeg/ffprobe 提取和校验音轨。登录、单节/批量下载、从字幕报告筛选、输出路径和参数见 [命令行使用与开发](cli.md#下载回放音频)。

CLI 的 ffmpeg 读取路径不转发浏览器 Cookie，媒体地址需要可直接访问。默认输出到 `output/audio/<course_id>/<日期>_<sub_id>.m4a`，并在每门课下维护 `媒体地址.json`。ffmpeg 通常仍需读取 MP4 中的视频数据，因此网络下载量会大于最终音频大小。

## 怎么选

| 场景 | 建议 |
|---|---|
| 日常使用、在课程页面顺手下载 | 浏览器插件 |
| 批量脚本、接口调试、需要媒体清单 | 命令行 `audio` 命令 |
| 只需要没有字幕的课时 | 插件“暂无字幕后补下载”或 CLI `--from-report` |

两种方式输出的都是 M4A，可以直接交给本地语音识别工具。转写流程见 [macOS 本地 Whisper 转写](macparakeet.md)。

## 常见问题

**下载被浏览器拦截**

检查地址栏右侧是否有下载被阻止的提示，点击允许/保留。

**登录状态失效**

插件使用当前浏览器会话；CLI 使用自己保存的登录态，需要先执行 `login`。两边状态不能互相替代。

**文件超过 1 GB**

插件会直接报错；可以改用 CLI 的 `audio` 命令，CLI 不使用插件的 1 GB 上限。

**回放是 HLS**

插件和 CLI 当前都不支持，需要等待后续版本。
